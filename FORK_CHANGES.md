# Форк Forkgram для Find N5: планшетный split + подвижный разделитель

Версия: **rail15** (10.11.2026), APK `/root/apk/Forkgram-rail15.apk` на VPS,
исходники `svpak@100.72.147.23:~/projects/tg-fork` (ветка `dev`, правки — коммит `fork/tablet-split`).

Собрано и проверено на OPPO Find N5 (Android 15, 2248×2480). Сборка: `bash ~/projects/tg-build.sh`,
APK на выходе `~/projects/tg-fork/out/app.apk`, установка `adb install -r`.

## Что сделано

### 1. Разделитель панелей тянется во всех разделах

- `AndroidUtilities.java`: `tabletSplitMinPaneDp` (80dp), `TABLET_SPLIT_DEFAULT_FRACTION = 0.35f`,
  `getTabletLeftFragmentSize()` считает минимум из `tabletSplitMinPaneDp`, а долю всегда берёт из
  `SharedConfig.tabletSplitFraction` — ширина сохраняется между разделами.
- `SharedConfig.java`: `tabletSplitFraction` (сохраняется в конфиг, `saveConfig()` на отпускании).
- `LaunchActivity.java`: split-контейнер — `leftPaneMinWidthDp()`, `updateSplitResizable()` в
  `onMeasure`; `onInterceptTouchEvent` ловит касание в пределах ±24dp от границы; жест работает и при
  пустой правой панели (убран guard по видимости правого `ActionBarLayout`).
- Проверено: «Чаты» 915 → 302 px, «Настройки» 1402 → 307 → 950 px, «Контакты» 299 → 951 px.

### 2. Узкая левая панель: «только иконки/аватарки»

- `DialogCell.java`: `railMode` включается по фактической ширине ячейки (< 112dp) — в этом режиме
  вместо текста пустые `StaticLayout` (`emptyRailLayout`), отключены плашки форума/премиум/verified/
  закреп/ошибок/таймера; `countLeft/countTop` перенесены к правому нижнему углу аватара, бейдж рисуется
  ПОСЛЕ аватара с обводкой — счётчик всегда поверх иконки.
- «Настройки»/«Профиль» при сужении сами сжимаются до одних иконок (без обрезки содержимого).
- Проверено: бейджи «13»/«36» поверх аватарок, серых плашек нет, сдвига/обрезки нет.

### 3. Компактные нижние вкладки

- `MainTabsLayout.java` / `MainTabsActivity.java`: если ширина < числа вкладок × 56dp — вместо ряда
  иконок одна кнопка активной вкладки со стрелкой, по нажатию `PopupWindow` со списком разделов
  (`openCompactTabsMenu()`, переключение через `selectTab`/`scrollToPosition`).

### 4. Исправленные падения и баги

- «Настройки → Устройства» падало (`SessionsActivity.java:230`): `useSimpleActionBar()` возвращал
  `true`, `actionBar == null`, NPE на `AccountSelector.addToMenu(...)`. Guard `actionBar != null`.
- После сужения и расширения панели текст не перерисовывался (столбики по одной букве, призрачные
  полосы). Причина: контейнер глушил `requestLayout()` от детей во время измерения, а страницы вкладок
  кэшируют ширину. Решение: `pendingRelayout` (запрос повторяется следующим кадром), `relayoutPanes()`
  — глубокий `requestLayout` по поддереву обеих панелей на `ACTION_UP` **и на каждом кадре
  перетаскивания** (троттлинг 60 мс оставлял мерцания), `splitLeftWidth` — ширина из `onMeasure`
  передаётся в `onLayout`, чтобы измерение и раскладка не расходились.

## Для следующей версии (не сделано)

1. **Узкие «Чаты»: верхняя часть.** Поле поиска и чип «Все 21» при 90dp обрезаются — спрятать их в
   `railMode`, оставив только аватарки.
2. **«Настройки» ниже 200dp.** Заголовки переносятся по слогам («Конфиденциально сть»). Варианты:
   ограничить минимум 200dp только для них (нужен надёжный признак раздела — имена классов в release
   обфусцированы, брать номер вкладки) или укоротить подписи в узком режиме.
3. **Переключение аккаунтов в «Устройствах».** После фикса NPE кнопка не появилась:
   `SimpleActionBarMenu` не является `ActionBarMenu` — нужен отдельный путь добавления.
4. **Конфликт жестов.** На «Профиле» горизонтальный свайп иногда прокручивает содержимое вместо
   разделителя — расширить зону захвата или ставить перехват раньше.
5. **Визуальная подсказка разделителя** — подсветка/утолщение полосы при касании.
6. **Отдельная доля ширины** для чатов и для остальных разделов (сейчас одна на всё).
7. **Сгиб устройства.** Проверить поведение при складывании/раскладывании (posture), сейчас не тестировали.
8. **Компактные вкладки**: проверить подписи на других языках и при увеличенном системном шрифте.

## Грабли (чтобы не наступить снова)

- В release-сборке имена фрагментов обфусцированы (`k52`, `cy0`) — условия по `SettingsActivity`/
  `ProfileActivity` тихо не работают, проверять `Log.d("FORKSPLIT", …)` + `adb logcat`.
- В контейнере нельзя выбрасывать `requestLayout()` от детей — только откладывать.
- Порт adb-подключения меняется после каждого включения «Отладки по Wi-Fi»; `adb pair` на VPS не
  работает (Debian-сборка), устройство уже сопряжено — нужен только актуальный порт.
- `vision_analyze` не читает PNG — конвертировать в JPG (PIL), координаты тапов умножать на коэффициент
  из ответа (обычно ×2).
